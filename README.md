# 🚀 Gerador de Código Multi-Linguagem

Este projeto é uma aplicação web simples que gera automaticamente códigos em várias linguagens de programação a partir de um texto digitado pelo usuário.

Ao escrever um texto (ex: *Hello, World!*), o sistema mostra como exibir esse texto em diferentes linguagens, com a opção de copiar o código com apenas um clique.

Acesse o projeto hospedado [aqui](https://htmlpreview.github.io/?https://github.com/alfredosilva12/print-generator/blob/main/index.html)

---

## ✅ Funcionalidades

- Entrada de texto personalizada
- Geração automática de código em várias linguagens
- Botão para copiar o código
- Interface moderna e responsiva
- Atualização em tempo real conforme o usuário digita
